About OSSense

OSSense is a Big Data Analytics project that processes large-scale GitHub activity using Apache Spark.

The analysis uses GH Archive event data and focuses on code activity, contributors, repositories, issues, pull requests, releases and forks.

DATA SOURCE GH Archive
PROCESSING Apache Spark

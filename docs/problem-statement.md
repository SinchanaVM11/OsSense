# Problem Statement

GitHub generates a massive volume of public development activity through code pushes, issues, pull requests, comments, releases, forks, and other events.

However, raw GitHub activity does not directly reveal how open-source projects evolve, how contributors collaborate, how efficiently issues and pull requests are handled, or what measurable patterns are associated with repository sustainability.

OSSense aims to process large-scale GitHub activity data using Big Data technologies and distributed analytics to identify these patterns.

## Objective

Develop a scalable Big Data Analytics system that processes more than 4 GB of GitHub activity data and analyzes:

1. Repository activity
2. Contributor collaboration
3. Issue resolution
4. Pull-request activity
5. Repository health indicators
